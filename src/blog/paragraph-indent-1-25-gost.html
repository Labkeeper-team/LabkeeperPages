Настройка абзацного отступа 1.25 см по ГОСТу для пояснительной записки

Дипломные работы

Что требует ГОСТ 7.32 к абзацному отступу

В тексте отчетов о НИР, пояснительных записок к дипломным проектам и диссертациям абзацный отступ (красная строка) стандартизирован абсолютно жестко:

«Абзацный отступ должен быть одинаковым по всему тексту отчета и равен 1,25 см».

Нормоконтролеры часто измеряют этот параметр буквально линейкой по распечатанному экземпляру. Любые отклонения (отступы табуляцией, пробелами или стандартный англо-американский отступ LaTeX в 15–20 pt) приводят к возврату работы на доработку.

Абзацный отступ 1.25 вкр онлайн: параметр parindent

В LaTeX точный абзацный отступ 1.25 вкр онлайн задается системной переменной \parindent в преамбуле документа (наряду с правильными полями листа, которые настраиваются через пакет geometry для полей по ГОСТ):

LaTeX
% Установка абзацного отступа ровно 1.25 см по ГОСТ
\setlength{\parindent}{1.25cm}

После этой директивы каждый новый абзац (начинающийся с пустой строки в коде TeX) автоматически сдвигается ровно на 12.5 мм.

Красная строка 1.25 см диплом: пакет indentfirst для первого абзаца

В англоязычной типографической традиции первый абзац после любого заголовка (\section, \subsection, \chapter) печатается без красной строки (слева вровень с заголовком). По этой причине базовый LaTeX подавляет отступ в первом абзаце.

В русской традиции красная строка 1.25 см диплом обязательна во всех абзацах без исключения, включая самый первый после названия главы. Для исправления подключите стандартный пакет indentfirst:

LaTeX
\usepackage{indentfirst} % Принудительный отступ 1.25 см даже в первом абзаце

Одна строчка подключения пакета решает проблему глобально во всем документе.

Межабзацный интервал parskip: почему нельзя оставлять пустые строки

В веб-верстке и американских документах принято разделять абзацы вертикальными отступами (блочный стиль). По российскому ГОСТу вертикальный интервал между абзацами внутри одного подраздела должен быть равен нулю.

Убедитесь, что параметр \parskip обнулен:

LaTeX
\setlength{\parskip}{0pt} % Никаких лишних вертикальных отступов между абзацами

Выравнивание по ширине полосы набора (Justify)

Текст ВКР обязательно выравнивается «по ширине» (justified) с включенным автоматическим переносом слов (подробное сравнение качества типографики смотрите в материале о выравнивании по ширине и переносах в LaTeX против Word). В LaTeX это поведение является стандартом по умолчанию, что гарантирует аккуратные ровные границы текста слева и справа.

Практические советы

1

Принудительное отключение отступа

Если в конкретной строке (например, перед формулой или подписью) отступ не нужен, используйте команду \noindent в начале строки.

2

Отступ в списках по ГОСТ

Для выравнивания списков enumerate и itemize вровень с абзацным отступом 1.25 см используйте пакет enumitem: \setlist{leftmargin=1.25cm}.
