Зачеркнутый текст: синтаксис с двойной тильдой ~~

Изучая зачеркнутый текст markdown синтаксис, вы встретите простое правило стандарта GitHub Flavored Markdown (GFM): текст с двух сторон оборачивается в двойные тильды ~~.

Markdown
Первоначальная гипотеза ~~не подтвердилась~~ была скорректирована в ходе эксперимента.
Цена лицензии: ~~5000 руб.~~ Бесплатно для студентов.

В браузере такой фрагмент компилируется в семантический HTML-тег <del> или <s>, отображаясь с аккуратной горизонтальной чертой по центру букв (такой же стиль вычеркивания выполненных пунктов применяется в интерактивных списках задач в Markdown).

Как подчеркнуть текст в Markdown: безопасные способы

В оригинальном синтаксисе Markdown намеренно нет символа для подчеркивания, поскольку в вебе подчеркнутый текст традиционно путают с гиперссылками (подробнее о специфике использования тегов читайте в статье об интеграции чистого HTML в Markdown). Однако при оформлении формуляров, бланков и рефератов вопрос, как подчеркнуть текст в markdown, возникает регулярно.

Для этого используется прямой встроенный HTML-тег <u>:

Markdown
Студент <u>Иванов Алексей Петрович</u> допущен к защите работы.
Обратите <u>особое внимание</u> на единицы измерения в СИ.

Тег <u> поддерживается парсером Labkeeper и корректно передается в итоговый PDF-документ.

Выделение маркером: тег <mark> и синтаксис ==текст==

Чтобы сымитировать желтый офисный текстовыделитель (хайлайтер), в зависимости от редактора используют два варианта:

  • В расширенных диалектах: двойные знаки равенства ==важный вывод==;
  • Универсальный HTML-способ: тег <mark>ключевой факт</mark>.

Это помогает акцентировать внимание научного руководителя или рецензента на ключевых тезисах статьи.

Употребление в научных работах и рецензиях

В итоговых версиях дипломов и диссертаций по ГОСТ зачеркивание не допускается, но на этапе согласования черновиков и переписки с научным руководителем зачеркивание и хайлайтер незаменимы для наглядной демонстрации внесенных правок.

Практические советы

1

Не путайте тильду со знаком подчеркивания

Одиночные знаки подчеркивания _текст_ в Markdown делают текст курсивом, а не подчеркнутым. Для подчеркивания всегда применяйте <u>текст</u>.
