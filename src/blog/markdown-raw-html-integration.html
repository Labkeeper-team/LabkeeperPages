Можно ли писать HTML в Markdown: официальная спецификация

Один из самых частых вопросов у новичков — можно ли писать html в markdown напрямую? Ответ: однозначно да. Создатель Markdown Джон Грубер изначально спроектировал формат как надстройку над HTML. Любой валидный HTML-тег может присутствовать в .md файле и будет обработан браузером без ошибок.

Вставка HTML тегов в Markdown: популярные сценарии

Прямая вставка html тегов в markdown требуется там, где базового синтаксиса недостаточно:

  • Вставка видео и аудио: теги <video>, <iframe>;
  • Подстрочные и надстрочные индексы химических элементов: H<sub>2</sub>O → H2O;
  • Центрирование подписей к рисункам и таблицам: <p align="center">Рисунок 1</p>;
  • Управление шириной и высотой изображений: <img src="img.png" width="300" /> (подробнее см. руководство по настройке размеров картинок в Markdown).

Выравнивание по ширине/центру и цветной шрифт

Для создания цветных предупреждающих рамок (а также при объединении ячеек таблиц через rowspan и colspan) используйте обычные блочные элементы со встроенными стилями:

HTML / Markdown
<div style="background-color: #f0f7ff; border-left: 4px solid #0066cc; padding: 12px;">
  <strong style="color: #0066cc;">Внимание!</strong> Результаты действительны только при стандартном давлении.
</div>

Правила вложенности Markdown внутри блочных HTML-тегов

Важное правило: если вы открыли блочный тег (например, <div>), многие парсеры перестают обрабатывать Markdown-синтаксис внутри него. Чтобы внутри HTML-блока продолжали работать звездочки или решетки, отделяйте содержимое пустой строкой либо добавляйте атрибут markdown="1".

Практические советы

1

Не злоупотребляйте сложными стилями

Используйте HTML точечно, только когда стандартных средств Markdown не хватает. Избыточный HTML лишает исходник его главного преимущества — легкости чтения.
