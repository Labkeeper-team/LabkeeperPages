Зачем нужен перечень иллюстраций и таблиц

В объемных дипломных проектах, диссертациях ВАК и научно-технических отчетах (ГОСТ 7.32-2017) требуется наличие перечня графического материала: «Список иллюстраций» (List of Figures, LoF) и «Список таблиц» (List of Tables, LoT). При ручном составлении любые изменения нумерации приводят к ошибкам.

В LaTeX список таблиц и рисунков в latex онлайн создается автоматически на основе подписей \caption{}, а оформление перечня иллюстраций latex гост легко настраивается пакетом tocloft.

Стандартные команды \listoffigures и \listoftables

Для вывода списков достаточно разместить в нужном месте документа (обычно сразу после оглавления \tableofcontents):

LaTeX
\tableofcontents % Основное оглавление
\newpage

\listoffigures   % Список рисунков
\newpage

\listoftables    % Список таблиц
\newpage

Кастомизация по ГОСТ 7.32 через пакет tocloft

По ГОСТ перед номером рисунка или таблицы должно стоять слово «Рисунок 1 — » или «Таблица 2 — », а заголовки должны быть переименованы на русский язык:

LaTeX
\usepackage[titles]{tocloft}

% Русификация заголовков
\renewcommand{\listfigurename}{Список иллюстраций}
\renewcommand{\listtablename}{Список таблиц}

% Префиксы перед номерами
\renewcommand{\cftfigpresnum}{Рисунок~}
\renewcommand{\cfttabpresnum}{Таблица~}

% Отступы для вмещения префикса
\settowidth{\cftfignumwidth}{Рисунок~99.~}
\settowidth{\cfttabnumwidth}{Таблица~99.~}

Отточия (лидеры) и выравнивание номеров страниц

В ГОСТ обязательно наличие точечных отточий от названия к номеру страницы. Пакет tocloft включает их командой \cftfigdotsep:

LaTeX
% Частота точек в отточиях
\renewcommand{\cftfigdotsep}{1}
\renewcommand{\cfttabdotsep}{1}

Включение списков в общее оглавление (tocbibind)

Чтобы списки иллюстраций, таблиц и список литературы по ГОСТ 7.0.5 отображались в основном оглавлении, подключите пакет tocbibind:

LaTeX
\usepackage[nottoc]{tocbibind}
% Опция nottoc исключает попадание самого оглавления в оглавление

Краткие подписи для списков в caption

Если подпись под графиком слишком длинная и содержит подробное описание эксперимента, используйте опциональный аргумент команды \caption[краткая]{полная}:

LaTeX
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\textwidth]{diagram.pdf}
    \caption[Схема экспериментальной установки]{Схема экспериментальной установки для исследования аэродинамического сопротивления профиля при сверхзвуковых скоростях потока.}
    \label{fig:setup}
\end{figure}

В перечень иллюстраций попадет только лаконичная фраза «Схема экспериментальной установки». Для форматирования самих числовых таблиц рекомендуем использовать выравнивание по разрядам в siunitx.

Практические советы

1

Двойная компиляция

Списки таблиц и рисунков формируются через служебные файлы .lof и .lot, поэтому для обновления номеров страниц требуется 2 прохода компиляции.

2

Оформление по ЕСКД

Для инженерных расчетно-пояснительных записок, требующих сквозных рамок и штампов, ознакомьтесь с руководством по ЕСКД и СПДС.
