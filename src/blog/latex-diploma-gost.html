ГОСТ 7.32 и требования к оформлению

ГОСТ 7.32-2017 «Отчёт о научно-исследовательской работе» — главный документ, которым руководствуются при оформлении дипломных работ и курсовых в российских вузах. Он задаёт требования к полям, шрифтам, заголовкам, нумерации и структуре.

Ключевые требования ГОСТ 7.32:

ПараметрТребование ГОСТ
ШрифтTimes New Roman, 12 или 14 пт
Межстрочный интервалПолуторный (1.5)
Поля: левое30 мм
Поля: правое10 мм
Поля: верхнее и нижнее20 мм
Абзацный отступ12,5 мм (~1,25 см)
Нумерация страницАрабские цифры, снизу по центру

Выбор класса документа и базовая настройка

Для оформления курсовой работы в LaTeX используйте класс report или article. Класс report предпочтительнее для дипломных работ с главами:

LaTeX
\documentclass[14pt,a4paper]{report}

\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}

% Поля по ГОСТ
\usepackage[
    left=30mm,
    right=10mm,
    top=20mm,
    bottom=20mm
]{geometry}

% Полуторный интервал
\usepackage{setspace}
\onehalfspacing

% Абзацный отступ
\setlength{\parindent}{1.25cm}

% Без отступа между абзацами
\setlength{\parskip}{0pt}

Поля страницы по ГОСТ

Пакет geometry — самый удобный способ задать поля. Параметры для ГОСТ 7.32:

LaTeX
\usepackage[
    a4paper,
    left=30mm,    % поле для переплёта
    right=10mm,
    top=20mm,
    bottom=20mm,
    headheight=14pt
]{geometry}
💡 Совет: Требования конкретного вуза могут отличаться от ГОСТ. Уточните методичку кафедры — иногда нижнее поле задаётся 25 мм, а не 20 мм.

Шрифт и межстрочный интервал

ГОСТ требует Times New Roman. При работе в XeLaTeX или LuaLaTeX подключите системный шрифт напрямую:

LaTeX (XeLaTeX)
\usepackage{fontspec}
\setmainfont{Times New Roman}
\setsansfont{Arial}
\setmonofont{Courier New}

При работе с pdfLaTeX используйте пакет pscyr или tempora как замену Times:

LaTeX (pdfLaTeX)
\usepackage{tempora}   % близкий аналог Times New Roman
% или
\usepackage{mathptmx}  % Times для текста и математики

Межстрочный интервал 1.5 устанавливается через пакет setspace:

LaTeX
\usepackage{setspace}
\onehalfspacing   % полуторный интервал

% Или задать вручную:
\renewcommand{\baselinestretch}{1.5}

Заголовки и разделы

По ГОСТ 7.32 заголовки разделов пишутся прописными буквами, подразделов — строчными с заглавной. Для управления стилями заголовков используйте пакет titlesec:

LaTeX
\usepackage{titlesec}

% Заголовки глав (ПРОПИСНЫЕ, по центру, полужирный)
\titleformat{\chapter}
    [block]
    {\normalfont\Large\bfseries\centering}
    {\thechapter}
    {1em}
    {\MakeUppercase}

% Подразделы (строчные, отступ, полужирный)
\titleformat{\section}
    {\normalfont\large\bfseries}
    {\thesection}
    {1em}
    {}

% Отступы вокруг заголовков
\titlespacing*{\chapter}{0pt}{0pt}{14pt}
\titlespacing*{\section}{0pt}{12pt}{6pt}

Оглавление и нумерация страниц

Оглавление формируется командой \tableofcontents. Для русскоязычного заголовка убедитесь, что подключён пакет babel с опцией russian:

LaTeX
% Нумерация снизу по центру
\usepackage{fancyhdr}
\pagestyle{fancy}
\fancyhf{}
\fancyfoot[C]{\thepage}
\renewcommand{\headrulewidth}{0pt}

% Оглавление
\tableofcontents
\newpage

% Глубина включения в оглавление
\setcounter{tocdepth}{3}

% Нумерация разделов до 3-го уровня
\setcounter{secnumdepth}{3}

Страница с оглавлением по ГОСТ не нумеруется (входит в общий счёт, но номер не печатается). Добавьте \thispagestyle{empty} после \tableofcontents.

Приложения

Приложения нумеруются русскими заглавными буквами (А, Б, В...) или латинскими (A, B, C). Для автоматической нумерации переопределите счётчик chapter:

LaTeX
\appendix
\renewcommand{\thechapter}{\Asbuk{chapter}}  % А, Б, В...
\renewcommand{\chaptername}{Приложение}

\chapter{Исходный код программы}
% содержимое приложения А

\chapter{Схема алгоритма}
% содержимое приложения Б
💡 Совет: Команда \Asbuk доступна при подключённом пакете babel с опцией russian.

Практические советы

1

Начните с готового шаблона

В Labkeeper доступны готовые шаблоны для курсовых и дипломных работ по ГОСТ 7.32. Откройте редактор, создайте новый проект и выберите шаблон «Дипломная работа ГОСТ».

2

Разбивайте документ на файлы

Используйте \include{chapter1} для вынесения каждой главы в отдельный .tex-файл. Это ускоряет компиляцию и упрощает навигацию в большом проекте.

3

Перекрёстные ссылки

Используйте \label и \ref для ссылок на рисунки, таблицы и формулы. LaTeX автоматически обновит все номера при добавлении нового элемента.

4

Список рисунков и таблиц

Добавьте \listoffigures и \listoftables после оглавления — ГОСТ требует эти списки для работ объёмом более 20 иллюстраций или таблиц.
