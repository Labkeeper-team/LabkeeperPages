Требования нормоконтроля к оформлению «Содержания»

В ГОСТ 7.32-2017 раздел именуется строго «СОДЕРЖАНИЕ» (заглавными буквами с выравниванием по центру). Основные требования:

  • Все разделы, подразделы и приложения перечисляются с указанием их порядковых номеров.
  • От названия каждого пункта до номера страницы идет непрерывная линия из точек (отточие).
  • Номера страниц выравниваются строго по правому краю без слова «стр.» или буквы «с» (а о том, как убрать номер с титульника, читайте в статье о нумерации диплома со второй страницы).
  • «Введение», «Заключение» и «Список использованных источников» не имеют номеров разделов, но обязательно входят в оглавление.

Автоматическое оглавление для диплома гост: команда tableofcontents

Чтобы сгенерировать автоматическое оглавление для диплома гост (в рамках единого шаблона оформления диплома по ГОСТ в LaTeX), достаточно вставить одну команду в месте размещения страницы содержания:

LaTeX
\tableofcontents
\clearpage

При первой компиляции TeX собирает названия разделов во вспомогательный файл .toc, а при втором проходе формирует идеально выровненную верстку со всеми номерами листов.

Содержание курсовой по госту онлайн: настройка глубины tocdepth

Чтобы содержание курсовой по госту онлайн не было перегружено мелкими пунктами, глубину отображения ограничивают счетчиком tocdepth:

LaTeX
% 1 = только разделы (section / chapter)
% 2 = разделы и подразделы (subsection) — СТАНДАРТ ДЛЯ ВКР
% 3 = включать пункты subsubsection
\setcounter{tocdepth}{2}

Настройка отточий и выравнивания номеров страниц (пакет tocloft)

В стандартном классе report или book у глав верхнего уровня отточия отключены по умолчанию. Для их принудительного включения по ГОСТ подключите пакет tocloft:

LaTeX
\usepackage{tocloft}

% Включаем отточия для глав и крупных разделов
\renewcommand{\cftsecleader}{\cftdotfill{\cftdotsep}}
\renewcommand{\cftchapleader}{\cftdotfill{\cftdotsep}}

% Переименовываем стандартное «Оглавление» в «СОДЕРЖАНИЕ»
\renewcommand{\contentsname}{\hfill СОДЕРЖАНИЕ \hfill}

Добавление ненумерованных разделов (Введение, Заключение, Список источников)

Если раздел объявляется со звездочкой (\section*{Введение}), LaTeX автоматически исключает его из оглавления. Чтобы вернуть его в содержание с правильным номером листа, добавьте команду \addcontentsline:

LaTeX
\section*{ВВЕДЕНИЕ}
\addcontentsline{toc}{section}{ВВЕДЕНИЕ}

Практические советы

Кликабельные пункты оглавления в PDF

Подключение \usepackage[hidelinks]{hyperref} превращает все строки содержания в интерактивные гиперссылки: клик по строке мгновенно переносит к нужному разделу.

2

Запрет переноса заголовка на новую страницу

Пакет tocloft гарантирует, что номера страниц никогда не оторвутся от отточия.
