Почему связка biblatex + biber заменила классический BibTeX

Хотя классический BibTeX по ГОСТ для списка литературы до сих пор популярен, оригинальная утилита bibtex была создана еще в 1985 году, когда не существовало стандарта Юникод (UTF-8). Из-за этого классический BibTeX часто ломал сортировку русских фамилий («А» оказывалась после «Я») и требовал сложных кодировочных ухищрений.

Современный тандем пакета biblatex и бэкенда biber полностью написан с поддержкой UTF-8, понимает правила русской грамматики и поддерживает официальный пакет адаптации biblatex-gost.

Настройка biblatex biber онлайн: преамбула с поддержкой ГОСТ

Идеальная настройка biblatex biber онлайн для российской диссертации или статьи:

LaTeX
\usepackage[
    backend=biber,         % Современный движок Biber
    style=gost-numeric,    % Числовые ссылки в квадратных скобках [1] по ГОСТ
    sorting=none,          % Сортировка по мере цитирования в тексте
    language=auto,
    autolang=other,
    defernumbers=true
]{biblatex}

\addbibresource{references.bib} % Подключение базы данных .bib

В конце документа список выводится одной командой: \printbibliography[title={Список использованных источников}].

Сортировка списка литературы biblatex: по языку, алфавиту и цитированию

Гибкая сортировка списка литературы biblatex настраивается параметром sorting:

  • sorting=none — источники нумеруются строго в порядке первого упоминания в тексте (стандарт для естественнонаучных отчетов);
  • sorting=nty — алфавитный порядок: Name (автор) $\to$ Title (название) $\to$ Year (год);
  • Сортировка сначала русские, затем иностранные: пакет biblatex-gost автоматически группирует записи по полю langid = {russian} и помещает кириллические источники в начало алфавитного перечня.

Современные типы записей в .bib файле (@online, @software, @thesis)

В отличие от старого BibTeX, в biblatex доступны современные семантические типы данных, позволяющие точно описать электронные ресурсы по ГОСТ 7.0.100:

references.bib
% Веб-страница с датой обращения
@online{react_docs,
    author  = {{Meta Platforms Inc.}},
    title   = {React: The library for web and native user interfaces},
    url     = {https://react.dev/},
    urldate = {2026-09-05},
    langid  = {english}
}

% Диссертация или дипломная работа
@thesis{ivanov_phd,
    author      = {Иванов, И. И.},
    title       = {Методы анализа графовых структур},
    type        = {phdthesis},
    institution = {МГУ им. М. В. Ломоносова},
    year        = {2025},
    langid      = {russian}
}

Цикл сборки: pdflatex -> biber -> pdflatex

Для генерации списка запускается цепочка: pdflatex main $\to$ biber main $\to$ pdflatex main. В облачном редакторе Labkeeper этот цикл выполняется полностью автоматически в фоновом режиме за доли секунды.

Практические советы

1

Удаление вспомогательных файлов при ошибках

Если вы кардинально изменили ключи в .bib файле, очистите кэш сборки (файлы .bbl и .bcf), чтобы Biber пересобрал индекс начисто.

2

Команда \parencite

Для стилей гарвардского цитирования (Автор, Год) используйте \parencite{key} для круглых скобок: (Иванов, 2025).
