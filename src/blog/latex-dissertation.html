Требования ВАК к диссертации

Высшая аттестационная комиссия (ВАК) устанавливает единые требования для кандидатских и докторских диссертаций, а также авторефератов. Ключевые параметры оформления кандидатской диссертации согласно «Положению о порядке присуждения учёных степеней» (Постановление Правительства РФ № 842):

ПараметрДиссертацияАвтореферат
Объём130–200 с. (технические науки)24 с. (кандидатская)
ФорматA4A5 (148×210 мм)
ШрифтTimes New Roman 14 птTimes New Roman 10–12 пт
Межстрочный интервал1.51.0–1.2
ПоляЛев. 30, пр. 10, вер./ниж. 20 ммВсе по 15–20 мм
⚠️ Важно: Диссертационный совет может вводить дополнительные требования. Перед началом верстки изучите требования конкретного совета на сайте вашего вуза.

Структура диссертации в LaTeX

Рекомендуемая структура проекта диссертации — несколько .tex-файлов, собранных в главный файл:

LaTeX
% main.tex — главный файл
\documentclass[14pt,a4paper]{report}
\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\usepackage[left=30mm,right=10mm,top=20mm,bottom=20mm]{geometry}
\usepackage{setspace}
\onehalfspacing
\usepackage[hidelinks]{hyperref}
\usepackage[backend=biber,style=gost-numeric]{biblatex}
\addbibresource{references.bib}

\begin{document}
    \include{titlepage}      % Титульный лист
    \include{abstract}       % Реферат (краткое содержание)
    \tableofcontents
    \include{intro}          % Введение
    \include{chapter1}       % Глава 1
    \include{chapter2}       % Глава 2
    \include{chapter3}       % Глава 3
    \include{conclusion}     % Заключение
    \printbibliography[title={Список использованных источников}]
    \appendix
    \include{appendix-a}     % Приложение А
\end{document}

Шаблон автореферата ВАК

Автореферат кандидатской диссертации печатается на листах формата A5 (148×210 мм), объёмом 24 страницы. Преамбула для автореферата:

LaTeX
\documentclass[12pt,a5paper]{article}
\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\usepackage[
    a5paper,
    left=20mm, right=15mm,
    top=20mm, bottom=20mm
]{geometry}
\usepackage{setspace}
\setstretch{1.1}

% Обязательные разделы автореферата:
% 1. Общая характеристика работы
%    — Актуальность, цели, задачи, научная новизна
%    — Практическая значимость
%    — Апробация результатов
%    — Публикации по теме диссертации
%    — Структура диссертации
% 2. Краткое содержание глав
% 3. Основные результаты и выводы
% 4. Список публикаций по теме диссертации

Обязательный раздел «Публикации по теме диссертации» должен содержать ссылки только на статьи из перечня ВАК. Для нумерации таких источников используйте отдельную категорию в biblatex:

LaTeX
% Публикации автора в перечне ВАК:
\printbibliography[
    keyword=vak,
    title={Публикации по теме диссертации}
]

Рамки и поля по ГОСТ

Некоторые вузы и советы требуют рамки на страницах диссертации по ГОСТ 2.104. Для создания рамок используется пакет fancyhdr в сочетании с tikz:

LaTeX
\usepackage{fancyhdr}
\usepackage{tikz}

\pagestyle{fancy}
\fancyhf{}

% Рамка через tikz в колонтитуле
\fancyhead[C]{%
    \begin{tikzpicture}[remember picture, overlay]
        \draw[line width=0.5pt]
            ([xshift=20mm, yshift=-20mm]current page.north west)
            rectangle
            ([xshift=-10mm, yshift=20mm]current page.south east);
    \end{tikzpicture}%
}
\fancyfoot[C]{\thepage}
\renewcommand{\headrulewidth}{0pt}

Перекрёстные ссылки

В диссертации активно используются ссылки на рисунки, таблицы, формулы и разделы. LaTeX автоматически отслеживает все номера:

LaTeX
% Метка на формуле:
\begin{equation}
    E = mc^2
    \label{eq:einstein}
\end{equation}

% Ссылка в тексте:
Из формулы~\eqref{eq:einstein} следует...

% Метка на рисунке:
\begin{figure}[h]
    \includegraphics[width=0.8\linewidth]{result.pdf}
    \caption{Результаты эксперимента}
    \label{fig:result}
\end{figure}

% Ссылка на рисунок:
На рисунке~\ref{fig:result} показано...

% Ссылка на раздел:
Подробнее в разделе~\ref{sec:method}.

Пакет cleveref позволяет автоматически добавлять слова «рис.», «табл.», «формула» перед номером:

LaTeX
\usepackage[russian]{cleveref}
% Теперь \cref{fig:result} даёт «рис. 1»
% \cref{eq:einstein} даёт «выражение (1)»

Практические советы

1

Начните верстку заблаговременно

Верстка диссертации занимает несколько дней при большом объёме. Начинайте настройку шаблона за 2–3 месяца до предполагаемой защиты, чтобы было время на правки.

2

Проверьте соответствие требованиям совета

Многие диссертационные советы имеют собственные шаблоны. Найдите готовые .tex-шаблоны от вашего совета или запросите их у секретаря.

3

Используйте \includeonly при работе

Команда \includeonly{chapter2} в преамбуле ускоряет компиляцию: LaTeX будет обрабатывать только указанные главы, сохраняя при этом корректную нумерацию всего документа.

4

Не забудьте про список сокращений

ВАК рекомендует включать перечень условных обозначений и сокращений. Пакет nomencl автоматизирует создание такого списка.
