Что такое ГОСТ Р 7.0.5-2008 и зачем он нужен

ГОСТ Р 7.0.5-2008 «Библиографическая ссылка» — российский стандарт, обязательный для дипломных и курсовых работ, диссертаций ВАК и научных статей, публикуемых в отечественных журналах. Он регламентирует порядок описания источников: порядок авторов, разделители, обозначения томов и страниц.

В отличие от международных стилей (APA, IEEE), ГОСТ использует специфические разделители («–», «//», «.–»), требует указывать общее число страниц для книг и придерживается строгого алфавитного порядка: сначала кириллические источники, затем латинские.

Пакет biblatex-gost: установка и подключение

Для оформления библиографии по ГОСТ 7.0.5 в LaTeX онлайн используется связка biblatex + стиль gost-numeric из пакета biblatex-gost. Подключите в преамбуле:

LaTeX
\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}

\usepackage[
    backend=biber,
    style=gost-numeric,   % числовые ссылки [1], [2]
    sorting=ntvy,         % по названию, году, тому, номеру
    language=auto,
    autolang=other
]{biblatex}

\addbibresource{references.bib}

Для именного стиля (автор, год) замените gost-numeric на gost-authoryear.

Правила заполнения .bib-файла для ГОСТ

ГОСТ требует указывать полное имя автора на языке оригинала. Для русскоязычных источников используйте кириллицу, для иностранных — латиницу. Примеры корректных записей:

BibTeX
@article{ivanov2023,
    author   = {Иванов, Иван Иванович and Петров, Сергей Николаевич},
    title    = {Методы оптимизации в задачах машинного обучения},
    journal  = {Журнал вычислительной математики},
    year     = {2023},
    volume   = {63},
    number   = {4},
    pages    = {589--602},
    language = {russian}
}

@book{smirnov2021,
    author    = {Смирнов, Алексей Владимирович},
    title     = {Введение в численные методы},
    publisher = {Наука},
    year      = {2021},
    address   = {Москва},
    pages     = {320},
    language  = {russian}
}

@online{labkeeper2026,
    author   = {{Labkeeper}},
    title    = {Онлайн-редактор LaTeX},
    url      = {https://labkeeper.io},
    urldate  = {2026-08-20},
    year     = {2026},
    language = {russian}
}
⚠️ Важно: Поле language = {russian} обязательно для корректного переключения разделителей в biblatex-gost. Без него разделители будут выводиться на латинице («and» вместо «и»).

Числовые ссылки в тексте

При стиле gost-numeric ссылки в тексте оформляются числами в квадратных скобках. Используйте команду \cite:

LaTeX
% Одна ссылка:
По данным работы~\cite{ivanov2023} установлено, что...

% Несколько ссылок:
Ряд исследований~\cite{ivanov2023, smirnov2021} подтверждает...

% Ссылка с указанием страниц:
\cite[с.~45]{smirnov2021}

% Вывод списка литературы:
\printbibliography[title={Список использованных источников}]

ГОСТ допускает как формат [1], так и формат [1, с. 45] при указании конкретных страниц. Если помимо библиографии в документе требуется оформить перечень графического материала, изучите нашу статью по генерации списков иллюстраций и таблиц по ГОСТ.

Именные ссылки (автор, год)

Стиль gost-authoryear применяется реже — обычно в гуманитарных дисциплинах. Команды для цитирования:

LaTeX
% Ссылка в скобках: (Иванов, 2023)
\parencite{ivanov2023}

% Ссылка в тексте: Иванов (2023) показал, что...
\textcite{ivanov2023}

% Только год: 2023
\citeyear{ivanov2023}

Сортировка и язык

ГОСТ Р 7.0.5 предписывает: сначала источники на русском языке, затем — иностранные. Для корректной сортировки укажите параметр sorting=ntvy:

LaTeX
\usepackage[
    backend=biber,
    style=gost-numeric,
    sorting=ntvy,
    language=auto,
    autolang=other,
    sortlocale=ru_RU   % гарантирует кириллицу перед латиницей
]{biblatex}
Параметр sorting Порядок сортировки
ntvy Название → Том → Номер → Год
nyt Название → Год → Том
ynt Год → Название → Том
none Порядок цитирования в тексте

Практические советы

1

Используйте Zotero для экспорта

Менеджер источников Zotero умеет экспортировать библиотеку в формат .bib. После экспорта вручную добавьте поля language для русскоязычных источников.

2

Перенос источников из Word

Если вы конвертируете готовую статью или диплом из текстового редактора, ознакомьтесь с руководством по переносу документов из Word в LaTeX, чтобы не потерять ссылки и формулы.

3

Проверка ошибок biber

Если список литературы не отображается, проверьте лог-файл на ошибки biber. Частая причина — несовместимые версии biblatex и biber. В Labkeeper версии всегда синхронизированы.

4

Разделение на подразделы

Если нужно разделить список на «Нормативные акты» и «Научную литературу», используйте \printbibliography[keyword=normative] и задавайте поле keywords в .bib-записях.
