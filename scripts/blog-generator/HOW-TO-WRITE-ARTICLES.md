# ✍️ Руководство и обязательный чек-лист для генерации статей

Этот документ содержит **строгий регламент для AI-агентов и авторов** по созданию новых статей блога Labkeeper, чтобы избежать любых ошибок независимо от используемой модели.

---

## 📌 Чек-лист для AI-агента (Строгие правила по шагам)

Перед тем как генерировать и публиковать новую пачку статей, агент **ОБЯЗАН** выполнить следующие шаги:

### 1. Проверка коллизий URL (`slug`)
* Агент должен открыть папку [`src/blog/`](file:///c:/Front/Git/LabkeeperPages/src/blog) и просмотреть имена всех существующих файлов `.html`.
* Новые значения `slug` **НЕ ДОЛЖНЫ совпадать ни на 100%, ни быть слишком похожими** на существующие статьи, чтобы не перезаписать контент и не создать дублей страниц в индексе поисковиков.

### 2. Определение и указание номера пачки (`batch`)
По умолчанию номер пачки берётся **из файла статьи самой свежей даты**:
1. **По умолчанию (автоматически):**
   - Агент (и скрипт `generate.js`) находит файл статьи с самой свежей датой в [`src/blog/`](file:///c:/Front/Git/LabkeeperPages/src/blog) (по полям `dateModified` / `datePublished` или дате изменения файла).
   - Из 2-й строки этого самого свежего файла считывается номер: `<!-- Пачка N -->`.
   - Этот номер `N` по умолчанию и используется для текущей пачки.
2. **Если создаётся следующая (новая) пачка:**
   - Если пользователь пишет *«Напиши пачку N»* или явно просит начать новую пачку, указывается `N` (или `текущий максимум + 1`).
* В результирующем HTML-файле на 2-й строке формируется комментарий:
  ```html
  <!DOCTYPE html>
  <!-- Пачка 2 -->
  <html lang="ru">
  ```

### 3. Органичное внедрение SEO-ключей (Главное правило: ДЛЯ ЛЮДЕЙ, а не для роботов!)
* В объекте статьи обязательно заполняется массив `"keywords": ["ключ 1", "ключ 2"]`.
* **В метатегах:** скрипт автоматически добавляет в `<head>`:
  - `<!-- SEO Ключи: ... -->` — для удобства проверки разработчиком/SEO-специалистом.
  - `<meta name="keywords" content="..." />` — для поисковых анализаторов.
* **В контенте статьи (человекопонятно и естественно):**
  - **Title (заголовок вкладки):** включает главный ключ или оба ключа в естественной связке (до 65–70 символов).
  - **H1:** лаконичный, привлекательный заголовок для читателя.
  - **H2 (подзаголовки):** хотя бы один или два подзаголовка H2 должны естественно содержать ключевые фразы (например: *«Как сделать сноски footnote в Markdown: базовый синтаксис»*).
  - **В тексте (первый абзац и тело статьи):** ключи вписываются **живым русским языком**, согласуясь по падежам и смыслу. Категорически запрещен «роботизированный» топорный спам ключами. Текст должен нести реальную практическую пользу для пользователя.

### 4. 100% Уникальность контента и отсутствие плагиата (Критично для поисковиков!)
* Тексты статей должны быть **абсолютно уникальными в глазах поисковых систем (Яндекс и Google)**. Категорически запрещен плагиат, слепое копирование чужих статей из сети или поверхностный рерайт.
* Каждая статья должна обладать высокой добавочной ценностью (*Helpful Content*): содержать оригинальные рабочие сниппеты кода, практические советы, разбор реальных типовых ошибок студентов и исследователей, а также нативные упоминания удобств работы в Labkeeper.

### 5. Карточка в каталоге блога (`src/blog.html`)
* Поля `cardTitle` и `cardDescription` должны быть краткими, ёмкими и кликабельными.
* Поле `categories` должно содержать только допустимые категории: `latex`, `markdown`, `labs`, `diploma`, `cv`, `articles`.
* Карточка автоматически помещается в начало сетки `#blog-grid` в файле `src/blog.html`.

### 6. Карточка на главной странице (`src/index.html`)
* На главной странице в блоке базы знаний перед футером (`.knowledge__swiper .swiper-wrapper`) статьи размещаются в **чистом статичном HTML без JavaScript**. Это критично для мгновенной индексации поисковыми роботами Яндекса и Google при обходе главной страницы.
* Скрипт-генератор автоматически проверяет и добавляет новый слайд в блок `knowledge` на главной.

### 7. Слайдер рекомендаций (`src/assets/js/slider.js`)
* Каждая новая статья должна попасть в реестр `ALL_BLOG_ARTICLES` в файле `src/assets/js/slider.js` с полями `url`, `title`, `text`, чтобы она участвовала в случайной ротации блока «Другие статьи» внутри всех материалов сайта.

### 8. Обязательный запуск обновления карты сайта (`sitemap.xml`)
* Каждый раз после добавления статей необходимо убедиться, что файл `src/sitemap.xml` обновился.
* Запуск происходит либо через `npm run blog:generate` (где генерация карты встроена нативно), либо отдельной командой:
  ```bash
  npm run sitemap
  ```

### 9. Фиксация в реестре ключевых слов
* После завершения генерации добавьте новые связки «URL ↔ Ключи» в файл:
  👉 [`scripts/blog-generator/SEO-KEYWORDS-REGISTRY.md`](file:///c:/Front/Git/LabkeeperPages/scripts/blog-generator/SEO-KEYWORDS-REGISTRY.md)
  Это нужно для удобного мониторинга позиций в Topvisor / Keys.so / Вебмастере.

## 🤖 Готовый промпт для генерации новой пачки статей

Отправьте этот промпт в чат нейросети для получения готового JSON:

```markdown
Напиши новую пачку статей (Пачка N) для блога научного онлайн-редактора Labkeeper.io в формате JSON.

Перед генерацией убедись, что предложенные slug уникальны и не повторяют существующие в /src/blog/.

Темы и ключи:
1. Заголовок: [...]
   Ключи: [...]
2. Заголовок: [...]
   Ключи: [...]

Строго соблюдай правила:
- Текст пишется ДЛЯ ЛЮДЕЙ: живой, экспертный, понятный технический язык без "воды".
- Ключи органично вплетены в Title, Description, подзаголовки H2 и первый абзац без спама.
- Поле "batch" равно N.

Формат JSON:
[
  {
    "slug": "уникальный-url-латиницей",
    "batch": 2,
    "keywords": ["ключ 1", "ключ 2"],
    "title": "Полное название статьи для H1",
    "pageTitle": "SEO Title с ключом — Labkeeper (до 65 символов)",
    "metaDescription": "SEO-описание до 160 символов с естественным вхождением ключа",
    "breadcrumbTitle": "Короткий заголовок крошек",
    "h1": "Заголовок первого уровня (&nbsp; для неразрывных пробелов)",
    "categories": ["markdown", "labs"],
    "datePublished": "2026-09-05",
    "dateModified": "2026-09-05",
    "readingTime": "6 мин",
    "cardTitle": "Заголовок для карточки в каталоге и на главной",
    "cardDescription": "Краткое описание на 1-2 предложения для карточки",
    "sliderTitle": "Короткий заголовок для слайдера рекомендаций",
    "sliderText": "Суть статьи в одно предложение",
    "sidebarText": "Текст плавающего правого баннера с призывом попробовать редактор",
    "ctaTitle": "Заголовок нижнего блока призыва к действию",
    "ctaText": "Текст о возможностях Labkeeper с акцентом на тему статьи",
    "toc": [
      { "id": "intro", "title": "Введение" },
      { "id": "syntax", "title": "Базовый синтаксис" },
      { "id": "examples", "title": "Практические примеры" },
      { "id": "faq", "title": "Частые ошибки" }
    ],
    "sections": [
      {
        "id": "intro",
        "title": "Введение",
        "html": "<p>Текст вводного параграфа...</p>"
      }
    ],
    "tips": [
      {
        "title": "Практический совет",
        "html": "<p>Полезная рекомендация...</p>"
      }
    ]
  }
]
```
